Entry for make.fun's "One Star, Five Stars for the Food" bounty: a program that writes one sentence (max 200 characters) — a one-star review of planet Earth by an alien tourist who still slips in a real compliment about the food.

Our alien is a culinary tourist: furious at the leaking sky, the crawling roads and the rude gravity — but the smoky satay from a street cart made all three of its stomachs sing, and it would cross back just to eat again.

## Run it

```sh
python3 main.py
```

It writes the entry sentence to `/output/entry.txt` (177 characters, one sentence, deterministic — byte-identical on every run).
